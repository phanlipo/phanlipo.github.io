Anleitung & Hinweise

Ein kleines Audio-Studio für unterwegs: Klingeltöne zuschneiden, Sprachnachrichten kürzen, zu leise Aufnahmen lauter machen, Musik ein- und ausblenden oder eine Datei in ein anderes Format umwandeln.

Bedienung

  1. Audiodatei wählen (oder hierher ziehen). Videos gehen auch – dann wird ihre Tonspur bearbeitet. Auf Android lässt sich eine Datei auch an die installierte App teilen.
  2. Windows/Computer: Als installierte App (Chrome oder Edge) steht sie im Explorer unter Öffnen mit – Rechtsklick auf die Datei; als Standard-App öffnet sie Dateien per Doppelklick. Mit Edge erscheint sie auch im Teilen-Menü von Windows.
  3. In der Wellenform einen Bereich mit dem Finger auswählen: Ziehen wählt einen neuen Bereich, Ziehen an einem Rand verschiebt nur diesen, kurzes Tippen setzt den näheren Rand. Genau geht es mit den Feldern Start und Ende (z. B. 1:23,5 oder 83,5 Sekunden).
  4. Auswahl abspielen zum Probehören.
  5. Bearbeiten – alles außer Mono wirkt auf die Auswahl (ist alles ausgewählt, auf die ganze Datei):
    • Auswahl behalten schneidet alles davor und danach weg (kürzen).
    • Auswahl herausschneiden entfernt den Bereich, der Rest wird zusammengefügt.
    • Lautstärke: Regler in Dezibel (+6 dB ≈ doppelt so laut, −6 dB ≈ halb so laut), dann Anwenden. Wird es zu laut, übersteuert die Datei (Hinweis erscheint).
    • Normalisieren macht die Auswahl so laut wie möglich, ohne zu übersteuern (Spitze bei −1 dB).
    • Einblenden / Ausblenden: die Lautstärke steigt über die Auswahl von 0 an bzw. fällt auf 0. Also z. B. die ersten 3 Sekunden auswählen und Einblenden tippen.
    • In Mono umwandeln mischt alle Kanäle zu einem (halbe Dateigröße bei WAV).
  6. Rückgängig nimmt die letzten Schritte zurück.
  7. Format wählen, Audiodatei erstellen, probehören, dann Speichern oder Teilen …. Gespeichert wird immer die ganze bearbeitete Datei.

Formate

  • Öffnen lässt sich, was der Browser abspielen kann: MP3, M4A/AAC, WAV, Ogg/Opus (auch WhatsApp-Sprachnachrichten), FLAC, WebM und die Tonspur von MP4-, MOV- und WebM-Videos.
  • WAV (16 Bit) ist verlustfrei. M4A (AAC) und Opus sind klein; 128 kbit/s klingt für Musik gut, für Sprache reichen 64 kbit/s. Ob AAC und Opus angeboten werden, hängt vom Browser ab (nicht verfügbare Formate sind ausgegraut).
  • MP3 geht in jedem Browser und spielt überall; bei gleicher Bitrate klingt AAC etwas besser. Der MP3-Encoder (LAME, ca. 300 KB) wird beim ersten Mal geladen und bleibt danach offline verfügbar.

Hinweise

  • Alles läuft im Browser, auch offline. Die Datei wird nicht hochgeladen und nicht gespeichert; gemerkt werden nur Format und Bitrate.
  • Die Datei wird zum Bearbeiten vollständig entpackt und im Arbeitsspeicher gehalten (Stereo: ca. 23 MB pro Minute, jeder Schritt zum Rückgängigmachen braucht noch einmal so viel). Für Aufnahmen bis etwa 30 Minuten reicht das auf jedem Handy; bei sehr langen Dateien kann der Browser abbrechen.
  • Bibliotheken: Mediabunny (MPL-2.0) zum Lesen und Schreiben der Dateien, für MP3 dessen Erweiterung mit LAME (LGPL).
  • KI-Agenten im Browser (WebMCP) können Angaben zur geöffneten Datei lesen, die Auswahl setzen, sie bearbeiten (rückgängig machbar) und eine Audiodatei erstellen lassen – eine Datei öffnen oder speichern können sie nicht.

A small audio studio on the go: trim ringtones, shorten voice messages, make quiet recordings louder, fade music in and out or convert a file into another format.

How to use

  1. Choose an audio file (or drag it here). Videos work too – their sound track is edited. On Android you can also share a file to the installed app.
  2. Windows/computer: as an installed app (Chrome or Edge) it is listed under Open with in Explorer – right-click the file; set as default app, it opens files with a double-click. With Edge it also appears in the Windows share menu.
  3. Select a range in the waveform with your finger: dragging selects a new range, dragging at an edge moves only that edge, a short tap moves the nearer edge. For precise values use the Start and End fields (e.g. 1:23.5 or 83.5 seconds).
  4. Play selection to listen.
  5. Edit – everything except mono works on the selection (on the whole file if everything is selected):
    • Keep selection removes everything before and after it (trim).
    • Cut out selection removes the range and joins the rest.
    • Volume: slider in decibels (+6 dB ≈ twice as loud, −6 dB ≈ half as loud), then Apply. If it gets too loud, the file clips (a hint appears).
    • Normalize makes the selection as loud as possible without clipping (peak at −1 dB).
    • Fade in / Fade out: the volume rises from 0 or falls to 0 across the selection. So e.g. select the first 3 seconds and tap Fade in.
    • Convert to mono mixes all channels into one (half the file size for WAV).
  6. Undo takes back the last steps.
  7. Choose a format, Create audio file, listen, then Save or Share …. The whole edited file is always saved.

Formats

  • Opens whatever the browser can play: MP3, M4A/AAC, WAV, Ogg/Opus (also WhatsApp voice messages), FLAC, WebM and the sound track of MP4, MOV and WebM videos.
  • WAV (16 bit) is lossless. M4A (AAC) and Opus are small; 128 kbit/s sounds good for music, 64 kbit/s is enough for speech. Whether AAC and Opus are offered depends on the browser (unavailable formats are greyed out).
  • MP3 works in every browser and plays everywhere; at the same bitrate AAC sounds a little better. The MP3 encoder (LAME, about 300 KB) is loaded the first time and is available offline after that.

Notes

  • Everything runs in the browser, offline too. The file is neither uploaded nor stored; only format and bitrate are remembered.
  • For editing, the file is fully decoded and kept in memory (stereo: about 23 MB per minute, every undo step needs as much again). That is fine on any phone for recordings up to about 30 minutes; very long files may make the browser give up.
  • Libraries: Mediabunny (MPL-2.0) to read and write the files, for MP3 its extension with LAME (LGPL).
  • AI agents in the browser (WebMCP) can read details of the opened file, set the selection, edit it (can be undone) and have an audio file created – they cannot open or save a file.
