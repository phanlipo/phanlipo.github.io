# phanlipo.github.io

Sammlung kleiner Web-Tools, veröffentlicht über GitHub Pages: **https://phanlipo.github.io/**

Die Startseite (`index.html`) ist eine Übersicht aller Seiten mit kurzer Doku.

## Seiten

| Seite | Ordner | Beschreibung |
|---|---|---|
| [Scan-Copy-SecurPharm](https://phanlipo.github.io/Scan-Copy-SecurPharm/) | `Scan-Copy-SecurPharm/` | securPharm-DataMatrix scannen, Werte kopieren, Verlauf |
| [Würfel & Münze](https://phanlipo.github.io/Wuerfel-Muenze/) | `Wuerfel-Muenze/` | Würfel und Münzwurf für Spiele, konfigurierbar, Einstellungen im localStorage |

## Neue Seite hinzufügen

1. Neuen Ordner anlegen, z. B. `Mein-Tool/`, darin eine `index.html`.
2. In der Startseite `index.html` eine weitere Karte im Abschnitt „Seiten“ ergänzen (vorhandene Karte kopieren).
3. Die Tabelle oben ergänzen.
