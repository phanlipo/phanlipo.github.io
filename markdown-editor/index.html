    Anleitung & Hinweise

    Ein Editor für Markdown – einfach formatierten Text, wie ihn README-Dateien, Notiz-Apps, Chat-Programme und KIs benutzen.

    Bedienung

    • Oben rechts wählst du die Darstellung: Text zeigt das Markdown, wie es ist (z. B. **fett**), Ansicht zeigt es formatiert. In beiden kannst du schreiben und bearbeiten.
    • Die Knöpfe unten formatieren den markierten Text oder die Zeile: Rückgängig/Wiederholen, Fett, Kursiv, Durchgestrichen, Überschrift (mehrmals tippen: Ebene 1, 2, 3, aus), Liste, nummerierte Liste, Aufgabenliste, Zitat, Code, Link, Tabelle und Trennlinie. Die Leiste lässt sich seitlich wischen.
    • In der Textdarstellung setzt Enter in einer Liste den nächsten Punkt; Enter auf einem leeren Punkt beendet die Liste.
    • In der Ansicht hakst du Aufgaben direkt per Tippen ab.
    • Oben links gibst du der Datei einen Namen. Ohne Namen gilt die erste Zeile.
    • Herunterladen speichert die Datei als .md, Teilen (oben, wenn das Gerät es kann) schickt sie an andere Apps – als Datei, oder als Text, wenn das Gerät keine Markdown-Dateien teilen kann.
    • Neue Datei (oben) beginnt eine leere Datei; die bisherige bleibt erhalten.
    • Im Menü ☰ liegen die Dateien: antippen zum Öffnen, daneben Teilen, Herunterladen und Löschen. Dort kannst du auch eine Datei vom Gerät öffnen (.md oder .txt). Als installierte App auf Android lassen sich Dateien auch direkt an die App teilen.
    • Windows/Computer: Als installierte App (Chrome oder Edge) steht sie im Explorer unter Öffnen mit – Rechtsklick auf die Datei; als Standard-App öffnet sie Dateien per Doppelklick. Mit Edge erscheint sie auch im Teilen-Menü von Windows.

    Hinweise

    • Bearbeitest du in der Ansicht, schreibt die App das Markdown neu und vereinheitlicht dabei die Schreibweise (z. B. Listen mit -, Fett mit **). Inhalte bleiben erhalten; selten genutzte HTML-Teile können verloren gehen. Wer die Schreibweise genau behalten will, bearbeitet in der Textdarstellung.
    • Unterstützt wird Markdown mit den GitHub-Erweiterungen: Tabellen, Aufgabenlisten, Durchgestrichen.
    • Bilder aus dem Internet lädt die App nicht (Datenschutz, offline) – sie zeigt stattdessen den Bildtext. Eingebettete Bilder (data:) werden angezeigt.
    • Alles wird automatisch in diesem Browser gespeichert und funktioniert offline; nichts wird hochgeladen. Der Platz im Browser ist begrenzt (einige MB für alle Dateien zusammen) – große Dateien besser herunterladen.
    • KI-Agent: Ein KI-Agent im Browser kann die Liste der Dateien und deren Inhalt lesen und eine neue Datei anlegen (WebMCP). Ändern oder löschen kann er bestehende Dateien nicht. Jeder Aufruf erscheint als Hinweis.
    • Bibliotheken: marked (MIT) wandelt Markdown in die Ansicht um, DOMPurify (Apache-2.0) entfernt dabei Skripte, turndown (MIT) macht aus der bearbeiteten Ansicht wieder Markdown.

    An editor for Markdown – plain text with simple formatting, as used by README files, note apps, chat apps and AIs.

    How to use

    • At the top right you pick the display: Text shows the Markdown as it is (e.g. **bold**), View shows it formatted. You can write and edit in both.
    • The buttons at the bottom format the selected text or the line: undo/redo, bold, italic, strikethrough, heading (tap again: level 1, 2, 3, off), list, numbered list, task list, quote, code, link, table and divider. Swipe the bar sideways for more.
    • In the text display, Enter in a list starts the next item; Enter on an empty item ends the list.
    • In the view you tick off tasks with a tap.
    • At the top left you give the file a name. Without a name the first line is used.
    • Download saves the file as .md, Share (at the top, if the device can) sends it to other apps – as a file, or as text if the device cannot share Markdown files.
    • New file (at the top) starts an empty file; the previous one is kept.
    • The menu ☰ holds the files: tap one to open it, next to it share, download and delete. There you can also open a file from the device (.md or .txt). As an installed app on Android you can also share files straight to the app.
    • Windows/computer: as an installed app (Chrome or Edge) it is listed under Open with in Explorer – right-click the file; set as default app, it opens files with a double-click. With Edge it also appears in the Windows share menu.

    Notes

    • When you edit in the view, the app rewrites the Markdown and makes the notation uniform (e.g. lists with -, bold with **). The content is kept; rarely used HTML parts may get lost. To keep the notation exactly, edit in the text display.
    • Markdown with the GitHub extensions is supported: tables, task lists, strikethrough.
    • Images from the internet are not loaded (privacy, offline) – the app shows the image text instead. Embedded images (data:) are shown.
    • Everything is saved automatically in this browser and works offline; nothing is uploaded. Browser storage is limited (a few MB for all files together) – better download large files.
    • AI agent: an AI agent in the browser can read the list of files and their content and create a new file (WebMCP). It cannot change or delete existing files. Each call shows a note.
    • Libraries: marked (MIT) turns Markdown into the view, DOMPurify (Apache-2.0) removes scripts from it, turndown (MIT) turns the edited view back into Markdown.
