    Anleitung & Hinweise

    Ein Ratespiel für kluge Köpfe: Gesucht ist ein geheimer Code aus vier oder fünf Farben in einer bestimmten Reihenfolge. Nach jedem Versuch verraten kleine Stifte, wie nah du dran bist. Knacke den Code in höchstens 10 Versuchen.

    Bedienung

    • Farben unten antippen – sie füllen die Plätze von links nach rechts (am Computer auch mit den Zifferntasten). Ein belegter Platz lässt sich antippen, um ihn neu zu wählen; die Rücktaste (Pfeil mit x) entfernt die letzte Farbe.
    • Sind alle Plätze belegt, mit Prüfen (oder Enter) den Versuch abgeben.
    • Jede Farbe trägt zusätzlich eine Nummer, damit sie sich auch ohne Farbsehen unterscheiden lässt.
    • Im Menü ☰: Aufgeben (zeigt den Code, zählt als nicht geknackt), die Spielart, die Schwierigkeit, eine Hilfe und die Statistik.

    Die Stifte

    • Gefüllter Stift: eine Farbe ist richtig und steht am richtigen Platz.
    • Ring: eine Farbe kommt im Code vor, steht aber an einem anderen Platz.
    • Die Stifte sagen nicht, welche Farbe gemeint ist – das ist das Rätsel. Jede Farbe im Code zählt nur einmal.

    Allein oder zu zweit

    • Allein: Das Handy denkt sich einen zufälligen Code aus.
    • Zu zweit: Einer wählt den Code verdeckt (mit dem Auge lässt er sich kurz zeigen) und tippt auf Raten lassen. Dann bekommen die anderen das Handy.

    Schwierigkeit

    • Leicht: 4 Plätze, 6 Farben, jede Farbe höchstens einmal.
    • Mittel: 4 Plätze, 6 Farben, Farben dürfen sich wiederholen.
    • Schwer: 5 Plätze, 8 Farben, Farben dürfen sich wiederholen.

    Die Hilfe „Wie viele Codes noch möglich sind“ zählt alle Codes, die zu allen bisherigen Stiften passen – bei nur noch einem ist der Code eindeutig.

    Gespeichert

    Das laufende Spiel (auch ein eigener Code), die Einstellungen und die Statistik der Spiele allein bleiben nur in diesem Browser (sichern und übertragen unter „Daten sichern“). Nichts wird an einen Server geschickt; die App läuft auch offline.

    A guessing game for clever minds: there’s a secret code of four or five colours in a certain order. After every guess, small pins tell you how close you are. Crack the code in at most 10 guesses.

    How to play

    • Tap colours at the bottom – they fill the places from left to right (on a computer also with the number keys). Tap a filled place to choose it again; the backspace key removes the last colour.
    • Once every place is filled, Check (or Enter) makes the guess.
    • Every colour also carries a number, so they can be told apart without seeing colour.
    • In the menu ☰: Give up (shows the code, counts as not cracked), the mode, the difficulty, a helper and the statistics.

    The pins

    • Filled pin: a colour is right and in the right place.
    • Ring: a colour is in the code, but in another place.
    • The pins don’t say which colour they mean – that’s the puzzle. Each colour of the code counts only once.

    Alone or two players

    • Alone: the phone thinks of a random code.
    • Two players: one picks the code hidden (the eye shows it for a moment) and taps Let them guess. Then the others get the phone.

    Difficulty

    • Easy: 4 places, 6 colours, each colour at most once.
    • Medium: 4 places, 6 colours, colours may repeat.
    • Hard: 5 places, 8 colours, colours may repeat.

    The helper “how many codes are still possible” counts every code that fits all pins so far – once only one is left, the code is certain.

    Stored

    The current game (including a code of your own), the settings and the statistics of games alone stay only in this browser (back them up or move them under “Back up data”). Nothing is sent to a server; the app also works offline.

    KI-Agenten (WebMCP)

    Ein KI-Agent kann das Spiel lesen (den geheimen Code erst nach dem Ende), einen Versuch abgeben und ein neues Spiel starten – auch mit einem eigenen Code, den du dann knackst. Jeder Versuch erscheint sofort auf dem Brett. Das klappt in Browsern mit WebMCP; was ein Agent tut, siehst du sofort hier in der App. Daten löschen, Sicherungen laden, Einstellungen zurücksetzen, Kamera, Mikrofon, Standort und Dateien öffnen sind für Agenten nie möglich, und sie schicken nichts an Server.

    AI agents (WebMCP)

    An AI agent can read the game (the secret code only once it is over), make a guess and start a new game – also with a code of its own for you to crack. Every guess shows up on the board right away. This works in browsers with WebMCP; whatever an agent does shows up here in the app right away. Deleting data, loading backups, resetting settings, camera, microphone, location and opening files are never available to agents, and they send nothing to servers.
