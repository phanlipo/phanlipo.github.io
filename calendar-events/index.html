    Anleitung & Hinweise

    Legt einen Termin an und übernimmt ihn in deinen Kalender – egal welchen. Die App selbst ist kein Kalender: Sie erzeugt den Termin, eingetragen wird er im Kalender deiner Wahl.

    Bedienung

    • Termin: Titel, Beginn und Ende eingeben – oder Ganztägig wählen (das Ende ist dann der letzte Tag). Wer den Beginn verschiebt, verschiebt das Ende mit, die Dauer bleibt gleich. Ort, Erinnerung, Wiederholung, Link und Beschreibung sind freiwillig.
    • Kalenderdatei (.ics): das übliche Format für Termine (iCalendar). Auf dem iPhone/iPad fragt Safari direkt, ob der Termin in den Kalender soll. Outlook, Apple Kalender, Samsung Kalender, Thunderbird und andere öffnen die Datei per Antippen bzw. Doppelklick.
    • Google Kalender: öffnet Google Kalender (App oder Webseite) mit dem ausgefüllten Termin – nur noch speichern. Der beste Weg auf Android, denn die Google-Kalender-App öffnet keine .ics-Dateien. Google übernimmt Wiederholungen, aber keine Erinnerung – es gilt die Standard-Erinnerung deines Google-Kalenders.
    • Outlook.com: öffnet den Termin in Outlook im Browser (privates Microsoft-Konto). Ohne Wiederholung und Erinnerung; für Firmenkonten und Wiederholungen die .ics-Datei nehmen.
    • Link teilen: Der ganze Termin steckt im Link. Wer ihn öffnet, sieht den Termin in dieser App und kann ihn mit einem Tipp in den eigenen Kalender übernehmen. Die Uhrzeit wird dabei in die Zeitzone des Empfängers umgerechnet. Ohne Teilen-Funktion wird der Link kopiert.
    • Als Text kopieren: Termin als lesbarer Text mit Link, z. B. für eine Nachricht.

    Meine Termine

    • Jeder Termin, den du speicherst, an Google/Outlook übergibst, teilst oder kopierst, landet in Meine Termine (die letzten 100). Antippen lädt ihn zum Ändern, × löscht ihn hier (nicht im Kalender).
    • Ein geladener Termin bleibt derselbe: Wird er geändert und neu gespeichert, ersetzt der Kalender den alten Eintrag meist (gleiche Kennung). Neuer Termin beginnt von vorn.
    • Alle als .ics speichern packt alle Termine in eine Datei.

    Kalenderdateien öffnen

    • Kalenderdatei öffnen liest eine .ics-Datei (z. B. eine Einladung aus einer E-Mail). Alle Termine darin landen in Meine Termine, der erste im Formular. So lässt sich eine Einladung auch auf Android in den Google Kalender bringen.
    • Android: In der installierten App die .ics-Datei über Teilen an Termin schicken. Windows, Mac & Co. (Chrome/Edge): in der installierten App per Öffnen mit.
    • Ungewöhnliche Wiederholungen aus der Datei („jeden 2. Dienstag“) bleiben erhalten und heißen dann Wie in der Datei.

    Zeitzone

    Uhrzeiten gelten in der Zeitzone dieses Geräts. Einmalige Termine stehen in der Datei in Weltzeit (UTC), wiederholte mit Zeitzone – so bleibt ein wöchentlicher Termin um 10 Uhr auch nach der Zeitumstellung um 10 Uhr.

    Datenschutz

    Termine bleiben in diesem Browser gespeichert, die App läuft offline. Nur wenn du Google Kalender oder Outlook.com antippst, gehen die Angaben des Termins an Google bzw. Microsoft – sie stehen in der Adresse, die sich dann öffnet. Beim Link zum Teilen steht der Termin hinter dem #; dieser Teil wird beim Öffnen nicht an den Server geschickt.

    KI-Agent

    Ein KI-Agent im Browser (WebMCP) kann einen Termin ins Formular eintragen und die Liste lesen. Er bekommt die .ics-Daten und Links zurück; in deinen Kalender kommt der Termin nur über die Knöpfe hier.

    Sets up an event and adds it to your calendar – whichever one you use. The app itself is not a calendar: it creates the event, your calendar of choice stores it.

    How to use

    • Event: enter a title, start and end – or choose All day (the end is then the last day). Moving the start moves the end too, so the duration stays the same. Place, reminder, repetition, link and description are optional.
    • Calendar file (.ics): the common format for events (iCalendar). On the iPhone/iPad Safari asks right away whether to add the event. Outlook, Apple Calendar, Samsung Calendar, Thunderbird and others open the file with a tap or double click.
    • Google Calendar: opens Google Calendar (app or website) with the event filled in – just save it. The best way on Android, as the Google Calendar app does not open .ics files. Google takes repetitions but no reminder – your Google Calendar's default reminder applies.
    • Outlook.com: opens the event in Outlook in the browser (personal Microsoft account). Without repetition and reminder; for work accounts and repetitions use the .ics file.
    • Share link: the whole event is in the link. Whoever opens it sees the event in this app and can add it to their own calendar with one tap. The time is converted to the recipient's time zone. Without a share function the link is copied.
    • Copy as text: the event as readable text with a link, e.g. for a message.

    My events

    • Every event you save, hand to Google/Outlook, share or copy goes into My events (the last 100). Tap one to edit it, × deletes it here (not in the calendar).
    • A loaded event stays the same event: changed and saved again, the calendar usually replaces the old entry (same identifier). New event starts afresh.
    • Save all as .ics puts all events into one file.

    Opening calendar files

    • Open calendar file reads an .ics file (e.g. an invitation from an email). All events in it go into My events, the first one into the form. This also gets an invitation into Google Calendar on Android.
    • Android: in the installed app, send the .ics file to Event via Share. Windows, Mac & co. (Chrome/Edge): in the installed app via Open with.
    • Unusual repetitions from the file ("every 2nd Tuesday") are kept and then called As in the file.

    Time zone

    Times are in the time zone of this device. One-off events are written to the file in universal time (UTC), repeating ones with the time zone – so a weekly event at 10:00 stays at 10:00 after the clocks change.

    Privacy

    Events stay saved in this browser, the app works offline. Only when you tap Google Calendar or Outlook.com do the event details go to Google or Microsoft – they are in the address that opens. In the share link the event comes after the #; this part is not sent to the server when the link is opened.

    AI agent

    An AI agent in the browser (WebMCP) can fill an event into the form and read the list. It gets the .ics data and links back; the event only gets into your calendar via the buttons here.
