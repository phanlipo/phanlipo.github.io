    Anleitung & Hinweise

    Sammelt eigene Messwerte – Gewicht, Blutdruck, Zählerstände, Pflanzenhöhe, Temperaturen … – und zeigt sie als Kurven über die Zeit.

    Bedienung

    • Profil: fasst zusammengehörige Messwerte zusammen, z. B. „Gesundheit“ oder „Stromzähler“. Beliebig viele Profile lassen sich anlegen, umbenennen und löschen.
    • Messwerte: je Profil bis zu 8, jeweils mit Name und Einheit. Jeder Messwert hat eine feste Farbe. × löscht den Messwert samt seiner Werte (nach Rückfrage).
    • Neuer Datenpunkt: Werte eintragen (Komma oder Punkt) und speichern. Der Zeitpunkt ist „jetzt“, lässt sich aber auch nachträglich wählen. Nicht jeder Messwert braucht bei jedem Datenpunkt einen Wert.
    • Auswertung: für jeden Messwert eine eigene Kurve – alle mit derselben Zeitachse, damit sie sich vergleichen lassen, aber jede mit eigener Werte-Achse (verschiedene Einheiten passen nicht auf eine Skala). Antippen oder darüberfahren zeigt den nächsten Wert. Darüber: letzter Wert, kleinster, größter und Mittelwert im gewählten Zeitraum.
    • Datenpunkte: Tabelle aller Werte, neueste zuerst. × löscht einen Datenpunkt.

    Export

    • Bild speichern: alle Kurven des Zeitraums als PNG (hell, zum Weitergeben oder Drucken). Bild teilen erscheint, wenn das Gerät Dateien teilen kann.
    • JSON speichern: das ganze Profil mit Messwerten und allen Datenpunkten (Zeit in UTC). Profil aus JSON laden legt daraus ein neues Profil an – so lässt sich ein einzelnes Profil auf ein anderes Gerät bringen.
    • CSV speichern: Tabelle für Excel, LibreOffice oder Numbers (Semikolon-getrennt, deutsches Komma; in der englischen Ansicht komma-getrennt mit Dezimalpunkt).

    Gespeichert

    Profile und Werte bleiben nur in diesem Browser gespeichert. Nichts wird an einen Server geschickt; die App läuft auch offline. Alle Profile auf einmal sichern oder übertragen: Daten sichern & übertragen.

    KI-Agent

    Ein KI-Agent im Browser (WebMCP) kann die Profile auflisten, Datenpunkte eintragen und die Werte samt Kennzahlen lesen. Eingetragene Werte erscheinen hier in der App. Löschen kann er nichts.

    Collects your own measurements – weight, blood pressure, meter readings, plant height, temperatures … – and shows them as curves over time.

    How to use

    • Profile: groups measurements that belong together, e.g. “Health” or “Electricity meter”. Create, rename and delete as many profiles as you like.
    • Measurements: up to 8 per profile, each with a name and a unit. Every measurement has a fixed colour. × deletes the measurement and its values (after asking).
    • New data point: enter values (comma or point) and save. The time is “now”, but you can also pick it afterwards. Not every measurement needs a value in every data point.
    • Charts: one curve per measurement – all on the same time axis so they can be compared, but each with its own value axis (different units do not fit on one scale). Tap or hover to see the nearest value. Above it: latest value, minimum, maximum and average in the chosen period.
    • Data points: table of all values, newest first. × deletes a data point.

    Export

    • Save image: all curves of the period as PNG (light, for passing on or printing). Share image appears if the device can share files.
    • Save JSON: the whole profile with its measurements and all data points (time in UTC). Load profile from JSON creates a new profile from it – the way to move a single profile to another device.
    • Save CSV: a table for Excel, LibreOffice or Numbers (in English comma-separated with a decimal point, in German semicolon-separated with a decimal comma).

    Storage

    Profiles and values stay in this browser only. Nothing is sent to a server; the app works offline too. To back up or move all profiles at once: Back up & transfer data.

    AI agent

    An AI agent in the browser (WebMCP) can list the profiles, add data points and read the values with key figures. Added values appear here in the app. It cannot delete anything.
