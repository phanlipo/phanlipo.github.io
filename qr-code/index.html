    Daten sichern & übertragen

    Einstellungen und Verläufe dieser App liegen nur in diesem Browser. Mit einer Sicherungsdatei lassen sie sich aufbewahren oder auf ein anderes Gerät bzw. in die installierte App übertragen.

    Anleitung & Hinweise

    Erzeugt QR-Codes direkt im Browser mit der Bibliothek qrcode-generator. Inhalt und Code verlassen das Gerät nicht.

    Bedienung

    • Link / Text: eintippen oder einfügen – der QR-Code wird sofort aktualisiert.
    • WLAN: Netzwerkname und Passwort eingeben. Handys verbinden sich nach dem Scannen mit einem Tipp, ohne das Passwort abzutippen.
    • Teilen … schickt das Bild an andere Apps (z. B. Messenger), Bild speichern lädt es als PNG herunter, Bild kopieren legt es in die Zwischenablage.
    • Fehlerkorrektur: Je höher, desto besser lässt sich ein verschmutzter oder teilweise verdeckter Code noch lesen – der Code wird dafür dichter.

    Link zum QR-Code

    • Unter dem Code steht ein Link zu diesem QR-Code. Wer ihn öffnet, sieht den Generator mit genau diesem Inhalt und derselben Fehlerkorrektur – praktisch zum Weitergeben, wenn jemand den Code selbst speichern oder drucken will.
    • Der Inhalt steht dabei im Link selbst (nicht auf einem Server). Bei WLAN-Codes enthält der Link also das Passwort.

    Links aus anderen Apps teilen (Android)

    • Die Seite einmal über das Browser-Menü „Zum Startbildschirm hinzufügen“ bzw. „App installieren“ installieren.
    • Danach erscheint QR-Code im Teilen-Menü anderer Apps (Chrome, YouTube, Maps …). Der geteilte Link wird sofort zum QR-Code und landet im Verlauf.
    • Auf dem iPhone gibt es das nicht – dort den Link kopieren und mit Einfügen übernehmen.

    Verlauf

    • Gespeichert wird beim Teilen, Speichern oder Kopieren des Bildes, mit Im Verlauf merken und bei Links, die aus anderen Apps geteilt wurden. Ein Tipp auf einen Eintrag öffnet ihn wieder.
    • Der Verlauf liegt nur in diesem Browser (höchstens 100 Einträge). WLAN-Passwörter stehen darin im Klartext – auf geteilten Geräten den Eintrag danach löschen.

    KI-Agenten (WebMCP)

    • Unterstützt der Browser WebMCP, kann ein KI-Assistent im Browser QR-Codes für Text, Links und WLAN erstellen und den Verlauf lesen. Der Code erscheint hier; Teilen, Speichern und Kopieren bleiben bei dir. Ein Hinweis zeigt, wenn ein Agent etwas ausgelöst hat.
    • Aus dem Verlauf bekommt ein Agent bei WLAN-Codes nur den Netzwerknamen, nie das Passwort.
    • Löschen und Sicherungen sind für Agenten nicht zugänglich. Es werden keine Daten an Server gesendet.

    Creates QR codes right in the browser with the library qrcode-generator. Content and code never leave the device.

    How to use

    • Link / Text: type or paste – the QR code updates at once.
    • Wi-Fi: enter the network name and password. After scanning, phones join with one tap without typing the password.
    • Share … sends the image to other apps (e.g. messengers), Save image downloads it as PNG, Copy image puts it on the clipboard.
    • Error correction: the higher, the better a dirty or partly covered code can still be read – the code gets denser.

    Link to the QR code

    • Below the code there is a link to this QR code. Whoever opens it sees the generator with exactly this content and the same error correction – handy for passing it on when someone wants to save or print the code themselves.
    • The content is inside the link itself (not on a server). For Wi-Fi codes the link therefore contains the password.

    Share links from other apps (Android)

    • Install the page once via the browser menu “Add to Home screen” or “Install app”.
    • Then QR Code appears in the share menu of other apps (Chrome, YouTube, Maps …). The shared link becomes a QR code at once and is added to the history.
    • iPhone does not offer this – copy the link there and use Paste.

    History

    • Codes are saved when the image is shared, saved or copied, with Keep in history and for links shared from other apps. Tapping an entry opens it again.
    • The history is stored in this browser only (at most 100 entries). Wi-Fi passwords are stored in plain text – delete the entry afterwards on shared devices.

    AI agents (WebMCP)

    • If the browser supports WebMCP, an AI assistant in the browser can create QR codes for text, links and Wi-Fi and read the history. The code appears here; sharing, saving and copying stay with you. A notice shows when an agent did something.
    • From the history, an agent only gets the network name of Wi-Fi codes, never the password.
    • Deleting and backups are not available to agents. No data is sent to any server.
