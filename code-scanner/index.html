  Anleitung & Hinweise
  
      
  
      Liest fast alle gängigen Codes und zeigt ihren Inhalt auf drei Arten: als Struktur (aufbereitet, z. B. Netzwerkname und Passwort eines WLAN-Codes), im Original (genau der gespeicherte Text, auf Wunsch als Bytes, dazu der Code neu erzeugt im selben Format) und als QR-Code (zum Weitergeben oder Ausdrucken). Alles läuft im Browser – nichts wird an einen Server geschickt, auch offline.
      
  
      Lesen
      
  
        
    
      • Kamera: „Scannen starten“ und den Code in den Rahmen halten. Bei mehreren Kameras lässt sich die Kamera wählen; Licht und Zoom gibt es, wenn das Handy sie anbietet.
        • 
    
      • Foto: Bild wählen, hierher ziehen oder einfügen (auch Bildschirmfotos). Stehen mehrere Codes im Bild, erscheint eine Auswahl. HEIC-Fotos öffnet Safari selbst; sonst lädt die App beim ersten HEIC-Foto einen Decoder (libheif, ca. 1,5 MB) aus ihren eigenen Dateien.
        • 
    
      • Text: Inhalt eines Codes einfügen, etwa von einem anderen Scanner, und aufbereiten lassen.
        • 
    
      • Teilen: Ein an die installierte App geteiltes Foto wird sofort ausgewertet.
        • 
  
      
  
      Codearten
      
  
      2D: QR-Code, Micro-QR, rMQR, DataMatrix (auch GS1), Aztec, PDF417, MicroPDF417, MaxiCode. Strichcodes: EAN-13, EAN-8, UPC-A, UPC-E, ISBN, Code 39, Code 93, Code 128 (auch GS1-128), ITF/ITF-14, Codabar, PZN, Code 32, GS1 DataBar, Telepen, DX-Filmkante.
      
  
      Aufbereitete Inhalte
      
  
        
    
      • Link mit Adresse und Parametern; Warnungen bei unverschlüsselten Links, IP-Adressen, Punycode-Domains (mögliche Fälschung) und Zugangsdaten im Link. Links öffnen sich erst nach einem Tipp.
        • 
    
      • WLAN, Kontakt (vCard, MeCard – speicherbar als .vcf), Termin (speicherbar als .ics), Ort, Telefon, SMS, E-Mail.
        • 
    
      • Zahlungen: GiroCode (EPC, SEPA-Überweisung) und Schweizer QR-Rechnung, mit IBAN-Prüfung.
        • 
    
      • Produkte: EAN/UPC/GTIN mit Prüfziffer und GS1-Länderpräfix (zeigt, wo die Nummer vergeben wurde – nicht das Herkunftsland), ISBN/ISSN, PZN.
        • 
    
      • GS1 (DataMatrix, GS1-128, QR, Digital Link): alle Datenbezeichner mit Namen, Datumsangaben, Gewichten und Prüfziffern; securPharm-Packungscodes (GS1 und IFA/PPN).
        • 
    
      • Bordkarten (IATA), Zwei-Faktor-Schlüssel (otpauth), Kryptowährungs-Adressen, JSON und andere App-Links.
        • 
  
      
  
      Bedienung
      
  
        
    
      • Ein Tipp auf einen Wert kopiert ihn. Passwörter und Schlüssel bleiben verdeckt, bis du „Zeigen“ tippst.
        • 
    
      • „Original“ zeigt Steuerzeichen (z. B. das GS1-Trennzeichen) als <GS>; „Inhalt kopieren“ kopiert den Text genau so, wie er im Code steht.
        • 
    
      • Nicht jedes Format lässt sich neu erzeugen (z. B. Micro-QR, MaxiCode, DataBar) – dann hilft der QR-Code.
        • 
  
      
  
      Gespeichert
      
  
      Der Verlauf (bis zu 200 Codes, abschaltbar) und die Einstellungen bleiben nur in diesem Browser (sichern und übertragen unter „Daten sichern“). Im Verlauf stehen auch Passwörter aus WLAN-Codes – lösche einzelne Einträge oder schalte den Verlauf ab, wenn das Gerät von anderen benutzt wird. Bibliothek: zxing-wasm (zxing-cpp) zum Lesen und Erzeugen der Codes.
      
  
      
  
      
  
      Reads almost all common codes and shows their content in three ways: as a structure (broken down, e.g. network name and password of a Wi-Fi code), in the original (exactly the stored text, as bytes if you like, plus the code created again in the same format) and as a QR code (to pass on or print). Everything runs in the browser – nothing is sent to a server, offline too.
      
  
      Reading
      
  
        
    
      • Camera: “Start scanning” and hold the code inside the frame. With several cameras you can pick one; light and zoom appear when the phone offers them.
        • 
    
      • Photo: choose an image, drag it here or paste it (screenshots too). With several codes in the picture you get a choice. Safari opens HEIC photos itself; otherwise the app loads a decoder (libheif, about 1.5 MB) from its own files for the first HEIC photo.
        • 
    
      • Text: paste the content of a code, e.g. from another scanner, and have it broken down.
        • 
    
      • Sharing: a photo shared to the installed app is evaluated right away.
        • 
  
      
  
      Code types
      
  
      2D: QR Code, Micro QR, rMQR, DataMatrix (GS1 too), Aztec, PDF417, MicroPDF417, MaxiCode. Barcodes: EAN-13, EAN-8, UPC-A, UPC-E, ISBN, Code 39, Code 93, Code 128 (GS1-128 too), ITF/ITF-14, Codabar, PZN, Code 32, GS1 DataBar, Telepen, DX film edge.
      
  
      Broken-down content
      
  
        
    
      • Link with address and parameters; warnings for unencrypted links, IP addresses, punycode domains (possible fake) and credentials in the link. Links only open after a tap.
        • 
    
      • Wi-Fi, contact (vCard, MeCard – can be saved as .vcf), event (can be saved as .ics), place, phone, SMS, email.
        • 
    
      • Payments: EPC QR code (GiroCode, SEPA transfer) and Swiss QR bill, with IBAN check.
        • 
    
      • Products: EAN/UPC/GTIN with check digit and GS1 country prefix (shows where the number was issued – not the country of origin), ISBN/ISSN, PZN.
        • 
    
      • GS1 (DataMatrix, GS1-128, QR, Digital Link): all application identifiers with names, dates, weights and check digits; securPharm pack codes (GS1 and IFA/PPN).
        • 
    
      • Boarding passes (IATA), two-factor keys (otpauth), cryptocurrency addresses, JSON and other app links.
        • 
  
      
  
      How to use
      
  
        
    
      • Tapping a value copies it. Passwords and keys stay hidden until you tap “Show”.
        • 
    
      • “Original” shows control characters (e.g. the GS1 separator) as <GS>; “Copy content” copies the text exactly as it is in the code.
        • 
    
      • Not every format can be created again (e.g. Micro QR, MaxiCode, DataBar) – the QR code helps then.
        • 
  
      
  
      Stored
      
  
      The history (up to 200 codes, can be switched off) and the settings stay only in this browser (back them up or move them under “Back up data”). The history also holds passwords from Wi-Fi codes – delete single entries or switch the history off if others use the device. Library: zxing-wasm (zxing-cpp) for reading and creating the codes.
      
  
      
  
  
      
  
      Dateien an die App geben
      
  
        
    
      • Android: App installieren (☰ → Als App installieren). Dann die Datei in Galerie, Dateien-, Mail- oder Messenger-App teilen und „Code-Scanner“ wählen – das klappt auch offline.
        • 
    
      • Windows/Computer: Als installierte App (Chrome oder Edge) steht sie unter Öffnen mit (Rechtsklick auf die Datei); als Standard-App öffnet sie Dateien per Doppelklick. Mit Edge erscheint sie auch im Teilen-Menü von Windows.
        • 
    
      • iPhone/iPad: Teilen an Web-Apps und Öffnen mit gibt es dort nicht – die Datei hier in der App auswählen.
        • 
  
      
  
      
  
      
  
      Giving files to the app
      
  
        
    
      • Android: install the app (☰ → Install as an app). Then share the file from the gallery, files, mail or messenger app and pick “Code Scanner” – this works offline too.
        • 
    
      • Windows/computer: as an installed app (Chrome or Edge) it is listed under Open with (right-click the file); set as default app, it opens files with a double-click. With Edge it also appears in the Windows share menu.
        • 
    
      • iPhone/iPad: sharing to web apps and Open with do not exist there – choose the file here in the app.
        • 
  
      
  
      
  
  
  
      
  
      KI-Agenten (WebMCP)
      
  
      Ein KI-Agent kann den Text eines Codes aufbereiten lassen (z. B. „Was steht in diesem GS1-Code?“), den gerade angezeigten Code und den Verlauf lesen. Passwörter von WLAN-Codes und Schlüssel von Zwei-Faktor-Codes bekommt er nie. Scannen, Speichern und Öffnen von Links bleiben bei dir. Das klappt in Browsern mit WebMCP; was ein Agent tut, siehst du sofort hier in der App. Daten löschen, Sicherungen laden, Einstellungen zurücksetzen, Kamera, Mikrofon, Standort und Dateien öffnen sind für Agenten nie möglich, und sie schicken nichts an Server.
      
  
      
  
      
  
      AI agents (WebMCP)
      
  
      An AI agent can have the text of a code broken down (e.g. “What is in this GS1 code?”) and read the code shown right now and the history. It never gets Wi-Fi passwords or two-factor keys. Scanning, saving and opening links stay with you. This works in browsers with WebMCP; whatever an agent does shows up here in the app right away. Deleting data, loading backups, resetting settings, camera, microphone, location and opening files are never available to agents, and they send nothing to servers.
