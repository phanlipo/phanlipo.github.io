    Weiterleitungen einfügen

    Format: Name = Ziel-Link, an der Stelle der Adresse steht {url}. {url:encode} kodiert die Adresse, {url:nohttps} lässt „https://“ weg, beides: {url:encode,nohttps}. Ohne {url} wird die Adresse kodiert ans Ende gehängt. Name und „=“ sind optional, Zeilen mit # werden übersprungen. „Alle als Text kopieren“ liefert genau dieses Format.

    Anleitung & Hinweise

    Leitet Links an einen Dienst deiner Wahl weiter – etwa an einen Archiv-, Lese- oder Übersetzungsdienst, der die Adresse als Parameter erwartet. Aus www.example.com wird mit dem Präfix https://test.de/?url= der Link https://test.de/?url=www.example.com.

    Bedienung

    • Beim ersten Start: Präfix (Anfang des Ziel-Links) und bei Bedarf Suffix (Ende, z. B. &lang=de) eintragen → Hinzufügen. Die Vorschau zeigt, was aus einer Beispieladresse wird.
    • Adresse kodieren (Standard) ersetzt Zeichen wie &, ? und /, damit die Adresse als ein Parameter ankommt. Ausschalten, wenn der Dienst die Adresse direkt im Pfad erwartet. „https://“ entfernen lässt das Protokoll weg.
    • Android, installierte App: einen Link aus einer anderen App an Weiterleiten teilen – die App öffnet sofort den Ziel-Link der gewählten Weiterleitung. Wer lieber erst schauen will: Menü ☰ → Einstellungen → Erst anzeigen.
    • Ohne Teilen: Adresse einfügen, Weiterleitung wählen (bei mehreren), Weiterleiten, Link kopieren oder Teilen. Steht die Adresse in einem längeren Text, wird der erste Link darin genommen.
    • Weitere Weiterleitungen, Bearbeiten und Löschen: Menü ☰ → Weiterleitungen verwalten. Die zuletzt gewählte gilt auch beim Teilen.
    • Viele auf einmal: Mehrere einfügen nimmt eine Liste als Text, eine Weiterleitung je Zeile, z. B. Archiv = https://web.archive.org/web/{url}. {url} steht für die Adresse; {url:encode} kodiert sie, {url:nohttps} lässt „https://“ weg. Schon vorhandene werden übersprungen; ist eine Zeile fehlerhaft, wird nichts übernommen und die Zeile genannt. Alle als Text kopieren liefert dasselbe Format – so lassen sich Weiterleitungen auch auf ein anderes Gerät bringen oder weitergeben.
    • iPhone und Kurzbefehle: Teilen an Web-Apps geht dort nicht. Stattdessen https://phanlipo.github.io/link-redirect/?url= plus die Adresse öffnen (z. B. per Kurzbefehl) – das wirkt wie Teilen.

    Sicherheit

    Weitergeleitet wird nur, wenn der fertige Link auf der Domain deines Präfixes bleibt. Ein fremder Link der Form …/link-redirect/?url=… kann dich so nur zu deinen eigenen Zielen schicken, nie auf eine beliebige Seite. Ein Präfix wie https://test.de ohne / am Ende wird deshalb abgelehnt.

    Gespeichert

    Gespeichert werden nur die Weiterleitungen und Einstellungen, in diesem Browser (sichern und übertragen unter „Daten sichern“). Adressen werden nicht gespeichert. Die App selbst schickt nichts an einen Server – erst beim Weiterleiten bekommt der Zieldienst die Adresse, so wie bei jedem Link. Die App läuft auch offline.

    Forwards links to a service of your choice – for example an archive, reader or translation service that expects the address as a parameter. With the prefix https://test.de/?url=, www.example.com becomes https://test.de/?url=www.example.com.

    How to use

    • First start: enter the prefix (start of the target link) and, if needed, a suffix (end, e.g. &lang=en) → Add. The preview shows what becomes of a sample address.
    • Encode address (default) replaces characters such as &, ? and / so the address arrives as one parameter. Turn it off if the service expects the address right in the path. Remove “https://” drops the protocol.
    • Android, installed app: share a link from another app to Redirect – the app opens the target link of the selected redirect right away. To look first: menu ☰ → Settings → Show first.
    • Without sharing: paste an address, pick a redirect (if there are several), then Redirect, Copy link or Share. If the address is part of a longer text, the first link in it is used.
    • More redirects, editing and deleting: menu ☰ → Manage redirects. The one picked last is also used when sharing.
    • Many at once: Paste several takes a list as text, one redirect per line, e.g. Archive = https://web.archive.org/web/{url}. {url} stands for the address; {url:encode} encodes it, {url:nohttps} drops “https://”. Existing ones are skipped; if a line is wrong, nothing is added and the line is named. Copy all as text gives the same format – handy for another device or for passing redirects on.
    • iPhone and Shortcuts: sharing to web apps is not possible there. Open https://phanlipo.github.io/link-redirect/?url= plus the address instead (e.g. from a shortcut) – it works like sharing.

    Security

    The app only redirects if the finished link stays on the domain of your prefix. A foreign link like …/link-redirect/?url=… can therefore only send you to your own targets, never to an arbitrary site. A prefix such as https://test.de without a / at the end is rejected for that reason.

    Stored

    Only the redirects and settings are stored, in this browser (back them up or move them under “Back up data”). Addresses are not stored. The app itself sends nothing to a server – only when you redirect does the target service get the address, like with any link. The app also works offline.

    KI-Agenten (WebMCP)

    Ein KI-Agent kann die gespeicherten Weiterleitungen lesen und für eine Adresse den Ziel-Link bauen lassen; der Link erscheint hier in der App. Weiterleiten (also die Adresse an den Zieldienst schicken) kann nur der Nutzer selbst. Das klappt in Browsern mit WebMCP; was ein Agent tut, siehst du sofort hier in der App. Daten löschen, Sicherungen laden, Einstellungen zurücksetzen, Kamera, Mikrofon, Standort und Dateien öffnen sind für Agenten nie möglich, und sie schicken nichts an Server.

    AI agents (WebMCP)

    An AI agent can read the saved redirects and have the target link built for an address; the link shows up here in the app. Only the user can actually redirect (that is, send the address to the target service). This works in browsers with WebMCP; whatever an agent does shows up here in the app right away. Deleting data, loading backups, resetting settings, camera, microphone, location and opening files are never available to agents, and they send nothing to servers.
