    Anleitung & Hinweise

    Ein Chat mit einem KI-Sprachmodell, das komplett auf diesem Gerät läuft. Nach dem einmaligen Download des Modells funktioniert er offline; Fragen und Antworten werden nirgends hingeschickt.

    Bedienung

    • Frage eintippen, Senden (Papierflieger). Beim ersten Mal wird das Modell heruntergeladen – am besten im WLAN. Danach startet es aus dem Speicher des Browsers. Welches Modell antwortet, steht neben „Chat“; ändern lässt es sich unter Einstellungen.
    • Die Antwort erscheint Wort für Wort; Stopp (Quadrat) bricht sie ab.
    • Teilen (Android, installierte App): In einer anderen App Text oder Link teilen → „KI-Chat“ wählen. Der Text steht dann im Eingabefeld; darunter die eigene Frage schreiben (z. B. „Fasse das zusammen“) und senden.
    • Kopieren-Symbol unter einer Antwort kopiert sie; die Symbole unter dem Eingabefeld beginnen einen neuen Chat bzw. kopieren den ganzen Chat. Am PC sendet Enter, Umschalt+Enter macht eine neue Zeile.
    • Das Modell kennt den bisherigen Chat. Wird er sehr lang, vergisst es die ältesten Nachrichten. Neuer Chat beginnt von vorn; frühere Chats stehen im Verlauf und lassen sich fortsetzen.
    • Unter Einstellungen lässt sich dem Modell eine feste Anweisung geben (z. B. „Antworte immer in Stichpunkten“) und die Länge der Antworten begrenzen.

    Modelle – woher sie kommen

    Alle Modelle stammen aus Googles Gemma-Familie (Google DeepMind). Die Dateien lädt der Browser direkt von Hugging Face (Konto onnx-community, in das Browser-Format ONNX umgewandelt), immer in einer fest eingestellten Version. Dabei sieht Hugging Face wie bei jedem Download die IP-Adresse – aber nie die Chats.

    ModellDownloadEignung
    Gemma 4 E2Bca. 2,3 GBEmpfohlen: deutlich bessere Antworten, auch auf Deutsch. Dieselbe Modellfamilie wie in Googles App „AI Edge Gallery“. Braucht viel Arbeitsspeicher und eine Grafikkarte, die 16-Bit-Rechnung (shader-f16) und Speicherblöcke von 1,2 GB am Stück erlaubt – das schaffen die meisten PCs und Macs, aber nur manche Handys. Zum Starten braucht es außerdem rund 5 GB freien Arbeitsspeicher (Geräte ab 8 GB). Die Seite prüft das und bietet Gemma 4 nur an, wo es laufen kann – sicher ist das auf Handys trotzdem nicht: Stürzt Chrome ab, bitte Gemma 3 1B nehmen. (Googles App nutzt eine eigene Rechen-Engine ohne diese Grenze.)
    Gemma 3 1Bca. 780–880 MBMittel: für einfache Fragen und Texte, läuft auf mehr Geräten.
    Gemma 3 270Mca. 290–340 MBSehr klein und schnell, aber für einen Chat zu schwach: erfindet viel und springt in längeren Antworten oft in andere Sprachen. Antworten sind deshalb auf ca. 300 Wörter begrenzt. Nur zum Ausprobieren.

    Lizenzen: Gemma 4 steht unter der Apache-2.0-Lizenz, Gemma 3 unter den Gemma-Nutzungsbedingungen (mit Richtlinie zur verbotenen Nutzung). Die Modelle sind nicht Teil dieser Seite, sondern werden nur auf Wunsch geladen. Die Rechen-Bibliotheken (transformers.js, ONNX Runtime) liegen auf dieser Seite.

    Gut zu wissen

    • WebGPU nötig: Das Modell rechnet auf der Grafikkarte. Ohne WebGPU (z. B. ältere Browser, Firefox auf Android) geht es nicht – dann erscheint oben ein Hinweis.
    • Kleine Modelle irren sich oft und erfinden Dinge. Sie kennen keine aktuellen Ereignisse und können nicht im Internet suchen. Wichtiges immer prüfen.
    • Während einer Antwort bleibt der Bildschirm an. Das Gerät kann dabei warm werden; der Akku wird stärker beansprucht.
    • Ein abgebrochener Download geht beim nächsten Senden weiter – die Dateien werden einzeln geladen und bleiben gespeichert.
    • Gespeichert wird nur in diesem Browser: Einstellungen und Chats (siehe „Daten sichern“), das Modell im Browser-Speicher. Heruntergeladene Modelle zeigt und löscht es.

    Absturz beim Starten von Gemma 4

    • Beim Start liest der Browser das Modell aus dem Speicher und legt es für die Grafikkarte an. Dafür braucht er kurzzeitig etwa doppelt so viel Arbeitsspeicher wie der Download groß ist – bei Gemma 4 rund 5 GB. Chrome auf Android gibt einem Tab oft weniger; dann beendet er die Seite.
    • Ob es reicht, lässt sich vorher nicht sicher erkennen: Browser melden den Arbeitsspeicher höchstens als „8 GB“, auch bei Handys mit 12 GB. Auf vielen Handys mit 8 GB klappt es nicht, auf PCs und Macs mit guter Grafikkarte meist schon.
    • Nach einem Absturz zeigt die Seite einen Hinweis, merkt sich das und wählt beim nächsten Mal ein kleineres Modell (Gemma 3 1B). Gemma 4 bleibt wählbar – klappt der Start doch einmal, verschwindet die Markierung. Der Download von Gemma 4 belegt ca. 2,3 GB; Heruntergeladene Modelle löscht ihn.
    • Googles App „AI Edge Gallery“ nutzt eine eigene Rechen-Engine, die das Modell direkt aus der Datei liest, statt es in den Arbeitsspeicher zu kopieren. Deshalb läuft Gemma 4 dort auch auf Handys, auf denen es im Browser nicht reicht.

    A chat with an AI language model that runs entirely on this device. After the model has been downloaded once it works offline; questions and answers are never sent anywhere.

    How to use

    • Type a question, press Send (paper plane). The first time, the model is downloaded – preferably over Wi-Fi. Afterwards it starts from the browser’s storage. The model that answers is shown next to “Chat”; change it under Settings.
    • The answer appears word by word; Stop (square) ends it.
    • Share (Android, installed app): share text or a link in another app → choose “AI Chat”. The text is put into the input field; write your own question below it (e.g. “Summarise this”) and send.
    • The copy icon below an answer copies it; the icons below the input field start a new chat or copy the whole chat. On a computer Enter sends, Shift+Enter starts a new line.
    • The model knows the chat so far. If it gets very long, it forgets the oldest messages. New chat starts over; earlier chats are in the history and can be continued.
    • Under Settings you can give the model a fixed instruction (e.g. “Always answer in bullet points”) and limit the length of answers.

    Models – where they come from

    All models are from Google’s Gemma family (Google DeepMind). The browser downloads the files directly from Hugging Face (account onnx-community, converted to the browser format ONNX), always in a fixed version. Like with any download, Hugging Face sees the IP address – but never the chats.

    ModelDownloadSuitable for

Starting it also needs about 5 GB of free memory (devices with 8 GB or more).     Good to know

    • WebGPU required: the model runs on the graphics card. Without WebGPU (e.g. older browsers, Firefox on Android) it does not work – a notice appears at the top.
    • Small models often get things wrong and make things up. They know nothing about current events and cannot search the internet. Always check what matters.
    • The screen stays on while an answer is written. The device may get warm and the battery drains faster.
    • An interrupted download continues the next time you send – the files are downloaded one by one and stay stored.
    • Only stored in this browser: settings and chats (see “Back up data”), the model in the browser’s storage. Downloaded models shows and deletes it.

    Crash while starting Gemma 4

    • When starting, the browser reads the model from storage and sets it up for the graphics card. For a moment this needs about twice the download size in memory – around 5 GB for Gemma 4. Chrome on Android often gives a tab less; then it closes the page.
    • Whether it is enough cannot be told reliably in advance: browsers report memory as “8 GB” at most, even on phones with 12 GB. On many phones with 8 GB it fails; on PCs and Macs with a good graphics card it usually works.
    • After a crash the page shows a notice, remembers it and picks a smaller model next time (Gemma 3 1B). Gemma 4 stays selectable – if it does start once, the mark goes away. The Gemma 4 download takes about 2.3 GB; Downloaded models deletes it.
    • Google’s “AI Edge Gallery” app uses its own engine that reads the model straight from the file instead of copying it into memory. That is why Gemma 4 runs there even on phones where the browser runs out of memory.

    Other

    • iPhone: an app added to the home screen has its own storage and downloads the model there again.
    • AI agent (WebMCP): an AI agent in the browser can read the current chat and ask the model a question once it has been downloaded; question and answer appear here in the chat.
