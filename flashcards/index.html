      Anleitung & Hinweise

      Karteikarten mit Frage und Antwort anlegen und so wiederholen, dass schwierige Karten öfter und gut gekonnte seltener drankommen.

      Bedienung

      • Stapel anlegen, laden, umbenennen oder löschen unter ☰ → Stapel verwalten. Bei mehreren Stapeln wechselst du oben auf der Seite.
      • Karten unter Karte hinzufügen eintragen; Tippen auf eine Karte in der Liste bearbeitet oder löscht sie.
      • Lernen: Frage lesen, Antwort überlegen, Karte antippen bzw. Antwort zeigen, dann ehrlich Gewusst oder Nicht gewusst wählen.
      • Unter Einstellungen: ob die Vorderseite, die Rückseite oder gemischt abgefragt wird, ob gemischt wird und ob nicht gewusste Karten in derselben Runde noch einmal kommen.

      Lernkasten (Leitner-System)

      Jede Karte liegt in einem von fünf Fächern. Neue und nicht gewusste Karten kommen in Fach 1 und sind sofort wieder dran. Gewusst rückt eine Karte ein Fach weiter; sie ist dann wieder fällig nach: Fach 2 – 1 Tag, Fach 3 – 3 Tage, Fach 4 – 7 Tage, Fach 5 – 21 Tage (bleibt in Fach 5). Lernen fragt nur fällige Karten ab, Alle Karten üben alle – auch dann zählen die Antworten.

      JSON-Dateien laden und speichern

      Unter ☰ speicherst du den aktuellen Stapel oder alle Stapel als JSON-Datei (mit Lernstand) und lädst solche Dateien wieder. Beim Laden kommt ein Stapel mit gleichem Namen zu dem vorhandenen dazu; Karten mit gleicher Vorder- und Rückseite werden übersprungen, ihr Lernstand bleibt. Aufbau:

      {
  "format": "flashcards",
  "formatVersion": 1,
  "decks": [
    { "name": "Englisch",
      "cards": [
        { "front": "Hund", "back": "dog" },
        { "front": "Katze", "back": "cat", "box": 2, "due": "2026-12-01T00:00:00.000Z" }
      ] }
  ]
}

      box (Fach 0–5, 0 = neu) und due (fällig ab) sind freiwillig. Auch einfachere Dateien werden angenommen: ein einzelner Stapel { "name": …, "cards": […] } oder nur eine Liste von Karten. Statt front/back gehen auch question/answer, q/a, term/definition oder Paare ["Hund", "dog"] – praktisch, um Karten mit einem anderen Programm oder einer KI zu erzeugen. Höchstens 5 MB je Datei, 100 Stapel, 5000 Karten je Stapel und 2000 Zeichen je Seite.

      Gespeichert

      Stapel, Karten, Lernstand und Einstellungen bleiben nur in diesem Browser gespeichert (sichern und übertragen unter „Daten sichern“ oder als JSON-Datei). Nichts wird an einen Server geschickt; die App läuft auch offline.

      Make flashcards with a question and an answer and review them so that hard cards come up more often and well-known ones less often.

      How to use

      • Decks: create, load, rename or delete them under ☰ → Manage decks. With several decks you switch at the top of the page.
      • Cards: enter them under Add card; tapping a card in the list edits or deletes it.
      • Learning: read the question, think of the answer, tap the card or Show answer, then honestly choose Knew it or Didn’t know.
      • Under Settings: whether the front, the back or both mixed are asked, whether the order is shuffled and whether unknown cards come again in the same round.

      Learning box (Leitner system)

      Every card sits in one of five boxes. New and unknown cards go to box 1 and are due right away. Knowing a card moves it one box up; it is due again after: box 2 – 1 day, box 3 – 3 days, box 4 – 7 days, box 5 – 21 days (stays in box 5). Learn asks only due cards, Practise all cards all of them – the answers count there too.

      Loading and saving JSON files

      Under ☰ you save the current deck or all decks as a JSON file (with progress) and load such files again. When loading, a deck with the same name is added to the existing one; cards with the same front and back are skipped and keep their progress. Layout:

      {
  "format": "flashcards",
  "formatVersion": 1,
  "decks": [
    { "name": "English",
      "cards": [
        { "front": "Hund", "back": "dog" },
        { "front": "Katze", "back": "cat", "box": 2, "due": "2026-12-01T00:00:00.000Z" }
      ] }
  ]
}

      box (box 0–5, 0 = new) and due (due from) are optional. Simpler files are accepted too: a single deck { "name": …, "cards": […] } or just a list of cards. Instead of front/back you may use question/answer, q/a, term/definition or pairs ["Hund", "dog"] – handy for making cards with another program or an AI. At most 5 MB per file, 100 decks, 5000 cards per deck and 2000 characters per side.

      Stored

      Decks, cards, progress and settings stay only in this browser (back them up or move them under “Back up data” or as a JSON file). Nothing is sent to a server; the app also works offline.

      KI-Agenten (WebMCP)

      Ein KI-Agent kann die Stapel auflisten, die Karten eines Stapels lesen und neue Karten in einen Stapel eintragen (fehlt der Stapel, wird er angelegt). Neue Karten erscheinen hier in der App. Das klappt in Browsern mit WebMCP; was ein Agent tut, siehst du sofort hier in der App. Daten löschen, Sicherungen laden, Einstellungen zurücksetzen, Kamera, Mikrofon, Standort und Dateien öffnen sind für Agenten nie möglich, und sie schicken nichts an Server.

      AI agents (WebMCP)

      An AI agent can list the decks, read the cards of a deck and add new cards to a deck (a missing deck is created). New cards appear here in the app. This works in browsers with WebMCP; whatever an agent does shows up here in the app right away. Deleting data, loading backups, resetting settings, camera, microphone, location and opening files are never available to agents, and they send nothing to servers.
