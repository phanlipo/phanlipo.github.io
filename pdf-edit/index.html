      Einstellungen und Verläufe dieser App liegen nur in diesem Browser. Mit einer Sicherungsdatei lassen sie sich aufbewahren oder auf ein anderes Gerät bzw. in die installierte App übertragen.

      Anleitung & Hinweise

      Bearbeitet PDF-Dateien direkt auf dem Gerät: mehrere Dateien zu einer zusammenführen, einzelne Seiten entfernen, drehen und neu sortieren. Der Inhalt der Seiten bleibt unverändert (Text bleibt Text, keine Qualitätsverluste).

      Bedienung

      1. PDF wählen öffnet eine oder mehrere Dateien. Jede weitere Datei wird hinten angehängt – so entsteht aus mehreren PDFs eine. Jede Datei bekommt einen Buchstaben (A, B, …); unten rechts im Vorschaubild steht, aus welcher Datei und von welcher Seite sie stammt.
      2. Teilen (Android): Ist die App installiert, erscheint „PDF bearb.“ im Teilen-Menü, z. B. in der Dateien-App oder bei einem Mail-Anhang. Auf dem iPhone geht das nicht; dort PDF wählen verwenden.
      3. Unter jedem Vorschaubild: ← / → verschiebt die Seite, ↻ dreht sie um 90° nach rechts, ✕ entfernt sie.
      4. In der Dateiliste verschieben ↑ / ↓ eine ganze Datei; die Seiten werden dabei nach Dateien geordnet. ✕ entfernt alle Seiten der Datei.
      5. Seiten auswählen: Für viele Seiten auf einmal die Nummern eintragen, z. B. 1, 3-5, 8- (8- = ab Seite 8 bis zum Ende), dann Drehen, Nur diese behalten oder Entfernen. Die Nummern sind die aktuellen Nummern oben links im Vorschaubild.
      6. Rückgängig nimmt die letzten Schritte zurück.
      7. PDF speichern lädt die neue Datei herunter. Teilen … (Handy) schickt sie direkt an eine andere App. Die Originaldateien bleiben unverändert.

      Gut zu wissen

      • Links und Kommentare auf den Seiten bleiben erhalten. Lesezeichen (Inhaltsverzeichnis am Rand) und ausfüllbare Formularfelder können beim Zusammenführen verloren gehen.
      • Passwortgeschützte PDFs lassen sich nicht öffnen – vorher in einem anderen Programm das Passwort entfernen.
      • Sehr große Dateien (mehrere hundert MB) können auf dem Handy am Arbeitsspeicher scheitern.

      Datenschutz & Speicher

      • Alles passiert im Browser auf dem Gerät; die Dateien werden nirgends hochgeladen. Die App funktioniert auch offline.
      • Nichts wird gespeichert: Nach dem Schließen oder Neuladen sind die geöffneten Dateien weg – vorher die neue PDF speichern.
      • Verwendet pdf-lib (MIT) zum Bearbeiten und pdf.js (Apache-2.0) für die Vorschaubilder.

      KI-Agenten

      Unterstützt der Browser WebMCP, kann ein KI-Agent die Seitenliste lesen, Seiten drehen und verschieben. Dateien öffnen, Seiten entfernen oder speichern kann er nicht.

      Edits PDF files right on your device: merge several files into one, remove, rotate and reorder pages. The content of the pages stays as it is (text stays text, no loss of quality).

      How to use

      1. Choose PDF opens one or more files. Every further file is added at the end – that is how several PDFs become one. Each file gets a letter (A, B, …); the bottom right of each preview shows which file and page it comes from.
      2. Share (Android): once the app is installed, “Edit PDF” appears in the share menu, e.g. in the Files app or for a mail attachment. iPhones do not support this; use Choose PDF there.
      3. Below each preview: ← / → moves the page, ↻ rotates it 90° to the right, ✕ removes it.
      4. In the file list, ↑ / ↓ moves a whole file; the pages are then ordered by file. ✕ removes all pages of the file.
      5. Select pages: for many pages at once, enter the numbers, e.g. 1, 3-5, 8- (8- = from page 8 to the end), then Rotate, Keep only these or Remove. The numbers are the current numbers at the top left of each preview.
      6. Undo takes back the last steps.
      7. Save PDF downloads the new file. Share … (phone) sends it straight to another app. The original files stay unchanged.

      Good to know

      • Links and comments on the pages are kept. Bookmarks (the outline in the side bar) and fillable form fields may be lost when merging.
      • Password-protected PDFs cannot be opened – remove the password in another program first.
      • Very large files (several hundred MB) may run out of memory on a phone.

      Privacy & storage

      • Everything happens in the browser on your device; the files are never uploaded. The app works offline, too.
      • Nothing is stored: after closing or reloading, the opened files are gone – save the new PDF first.
      • Uses pdf-lib (MIT) for editing and pdf.js (Apache-2.0) for the previews.

      AI agents

      If the browser supports WebMCP, an AI agent can read the page list, rotate and move pages. It cannot open files, remove pages or save.
