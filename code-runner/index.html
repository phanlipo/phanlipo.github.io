  Anleitung & Hinweise
  
    
  
    Kleine Programme in Python oder JavaScript schreiben und sofort ausführen – zum Lernen, Ausprobieren und Rechnen. Alles läuft in diesem Browser, es gibt keinen Server.
    
  
    Bedienung
    
  
      
    
    • Oben die Sprache wählen, Code schreiben, unten Ausführen tippen (Tastatur: Strg+Enter). Die Ausgabe erscheint darunter bzw. am Computer rechts daneben. Fehler sind rot, das Ergebnis der letzten Zeile steht hinter einem Pfeil (→).
      • 
    
    • Läuft ein Programm zu lange oder endlos, beendet Stopp es.
      • 
    
    • Die Leiste unten fügt Zeichen ein, die auf der Handy-Tastatur schwer zu finden sind, und rückt Zeilen ein (⇥) oder aus (⇤). Mit Tastatur rückt Tab ein; zum Verlassen des Feldes vorher Esc drücken.
      • 
    
    • Eingaben: Ein Programm kann hier nicht mittendrin nachfragen. Was input() (Python) bzw. prompt() oder readline() (JavaScript) lesen soll, vorher im Menü ☰ unter Eingabe für das Programm eintragen – eine Zeile je Aufruf.
      • 
    
    • Im Menü ☰ liegen außerdem Beispiele, die gespeicherten Skripte, Datei öffnen (.py, .js, .txt), Als Datei herunterladen und die Einstellungen (Schriftgröße, Zeilenumbruch).
      • 
    
    • Der Code im Editor wird automatisch gemerkt – je Sprache einer. Jeder Lauf beginnt frisch: Variablen aus dem letzten Lauf gibt es nicht mehr.
      • 
  
    
  
    Was geht – und was nicht
    
  
      
    
    • Python ist das echte Python (CPython als WebAssembly, Pyodide) mit der Standardbibliothek: math, random, json, re, datetime, itertools, statistics … Zusatzpakete wie numpy oder pandas gibt es nicht – sie müssten von einem fremden Server geladen werden.
      • 
    
    • Beim ersten Start von Python lädt die App den Interpreter von dieser Seite (ca. 13 MB, einmalig). Danach geht auch Python offline. JavaScript läuft sofort.
      • 
    
    • JavaScript läuft in der JavaScript-Engine des Browsers, aber ohne Seite: kein document, kein window. Ausgaben mit console.log(); await geht direkt auf oberster Ebene, setTimeout auch.
      • 
    
    • Bash/Shell gibt es nicht: Dafür bräuchte es ein ganzes Linux im Browser.
      • 
    
    • Sehr lange Ausgaben werden gekürzt (nach ca. 1 Million Zeichen je Lauf).
      • 
  
    
  
    Sicherheit & Datenschutz
    
  
      
    
    • Der Code läuft abgetrennt von der Seite in einem eigenen Hintergrund-Prozess (Worker). Netzwerkzugriffe (fetch, XMLHttpRequest, WebSocket) und der Browser-Speicher sind dort gesperrt – ein Programm kann also weder Daten verschicken noch die Daten anderer Apps dieser Seite lesen.
      • 
    
    • Das ist ein Schutz vor Versehen, keine vollständige Sandbox. Führe nur Code aus, den du verstehst oder dem du vertraust.
      • 
    
    • Code, Eingabe und gespeicherte Skripte liegen nur in diesem Browser. Nichts wird hochgeladen.
      • 
  
    
  
    KI-Agenten
    
  
    Browser mit WebMCP können die App als Werkzeug nutzen: Ein KI-Agent kann Code ausführen (er erscheint im Editor, die Ausgabe wie gewohnt darunter) sowie Code und letzte Ausgabe lesen. Hast du ungespeicherten Code im Editor, legt die App ihn vorher unter Skripte ab.
    
  
    
  
    
  
    Write small programs in Python or JavaScript and run them right away – for learning, trying things out and calculating. Everything runs in this browser; there is no server.
    
  
    How to use
    
  
      
    
    • Choose the language at the top, write code, tap Run at the bottom (keyboard: Ctrl+Enter). The output appears below, or next to the editor on a computer. Errors are red; the value of the last line follows an arrow (→).
      • 
    
    • If a program runs too long or forever, Stop ends it.
      • 
    
    • The bar at the bottom inserts characters that are hard to find on a phone keyboard and indents (⇥) or outdents (⇤) lines. With a keyboard Tab indents; press Esc first to leave the field.
      • 
    
    • Input: a program cannot ask in the middle of a run here. Enter what input() (Python) or prompt() / readline() (JavaScript) should read beforehand in the menu ☰ under Input for the program – one line per call.
      • 
    
    • The menu ☰ also holds examples, your saved scripts, Open file (.py, .js, .txt), Download as file and the settings (font size, line wrapping).
      • 
    
    • The code in the editor is remembered automatically – one per language. Every run starts fresh: variables from the last run are gone.
      • 
  
    
  
    What works – and what does not
    
  
      
    
    • Python is the real Python (CPython as WebAssembly, Pyodide) with its standard library: math, random, json, re, datetime, itertools, statistics … Extra packages such as numpy or pandas are not available – they would have to be loaded from another server.
      • 
    
    • The first time you use Python the app loads the interpreter from this site (about 13 MB, once). After that Python works offline too. JavaScript runs right away.
      • 
    
    • JavaScript runs in the browser's JavaScript engine, but without a page: no document, no window. Print with console.log(); top-level await works, and so does setTimeout.
      • 
    
    • There is no Bash/shell: that would need a whole Linux inside the browser.
      • 
    
    • Very long output is cut off (after about 1 million characters per run).
      • 
  
    
  
    Security & privacy
    
  
      
    
    • The code runs separated from the page in its own background process (worker). Network access (fetch, XMLHttpRequest, WebSocket) and browser storage are blocked there – so a program can neither send data anywhere nor read the data of other apps on this site.
      • 
    
    • This protects against accidents; it is not a complete sandbox. Only run code you understand or trust.
      • 
    
    • Code, input and saved scripts stay in this browser. Nothing is uploaded.
      • 
  
    
  
    AI agents
    
  
    Browsers with WebMCP can use the app as a tool: an AI agent can run code (it appears in the editor, the output below as usual) and read the code and the last output. If the editor holds unsaved code, the app puts it under Scripts first.
    
  
    
  
  
    Fehlersuche
    
  
    Klappt etwas nicht? Erst das Problem auslösen, dann die Diagnose kopieren und weitergeben. Sie enthält Browser, App-Version, Status und ein Protokoll der letzten Schritte – keine eingegebenen Inhalte.
