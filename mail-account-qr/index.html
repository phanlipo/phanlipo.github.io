    Anleitung & Hinweise

    Thunderbird auf dem Handy (Android) kann E-Mail-Konten aus einem QR-Code übernehmen. Thunderbird am Computer erzeugt solche Codes unter Einstellungen → Export für Mobilgeräte. Diese App kann beides auch ohne Computer: Codes erstellen und Codes lesen.

    Code erstellen

    • E-Mail-Adresse eintragen. Für bekannte Anbieter (Gmail, Outlook/Hotmail, GMX, WEB.DE, T-Online, Posteo, mailbox.org) werden die Server automatisch eingetragen – bitte trotzdem prüfen, die Angaben sind ohne Gewähr.
    • Sonst Server, Port, Verschlüsselung und Anmeldung aus den Unterlagen deines Anbieters eintragen. Üblich: IMAP mit SSL/TLS auf Port 993, SMTP mit STARTTLS auf 587 oder SSL/TLS auf 465.
    • Mehrere Konten passen in einen Code; ab vier Konten entstehen mehrere Codes (je drei Konten, wie bei Thunderbird). Auf dem Handy nacheinander scannen.
    • Passwörter sind freiwillig. Ohne Passwort fragt Thunderbird auf dem Handy danach. Konten mit OAuth2 (Gmail, Outlook) brauchen kein Passwort im Code.

    Code lesen

    • Den Code von Thunderbird am Computer mit der Kamera scannen, ein Bildschirmfoto davon wählen oder seinen Text einfügen.
    • Die Kontodaten erscheinen mit Server, Port und Benutzername – praktisch, um sie von Hand in eine andere Mail-App (z. B. auf dem iPhone) einzutragen. Jeder Wert lässt sich kopieren.
    • „In ‚Code erstellen‘ übernehmen“ legt die Konten in deine Liste, um sie anzupassen und neu als Code zu zeigen.

    Gespeichert

    Die Liste der Konten (Adressen, Server, Benutzernamen) bleibt nur in diesem Browser gespeichert (sichern und übertragen unter „Daten sichern“). Passwörter werden nie gespeichert und gelesene Codes auch nicht – beides ist nach dem Schließen der Seite weg. Nichts wird an einen Server geschickt; die App läuft auch offline.

    Achtung: Ein Code mit Passwort ist so geheim wie das Passwort selbst. Nicht fotografieren lassen und nicht teilen.

    Bibliotheken

    QR-Codes zeichnet qrcode-generator (MIT); Codes liest der Browser selbst (BarcodeDetector) oder zxing-wasm (MIT).

    Thunderbird on the phone (Android) can take email accounts from a QR code. Thunderbird on the computer makes such codes under Settings → Export for Mobile. This app does both without a computer: create codes and read codes.

    Create a code

    • Enter the email address. For well-known providers (Gmail, Outlook/Hotmail, GMX, WEB.DE, T-Online, Posteo, mailbox.org) the servers are filled in – please check them anyway, no guarantee.
    • Otherwise enter server, port, encryption and sign-in from your provider’s documents. Common: IMAP with SSL/TLS on port 993, SMTP with STARTTLS on 587 or SSL/TLS on 465.
    • Several accounts fit into one code; from four accounts on there are several codes (three accounts each, like Thunderbird). Scan them one after another on the phone.
    • Passwords are optional. Without one, Thunderbird on the phone asks for it. Accounts with OAuth2 (Gmail, Outlook) need no password in the code.

    Read a code

    • Scan the code from Thunderbird on the computer with the camera, choose a screenshot of it or paste its text.
    • The account settings show up with server, port and user name – handy to enter them by hand in another mail app (e.g. on the iPhone). Every value can be copied.
    • “Use in Create code” puts the accounts into your list, to change them and show them as a new code.

    Stored

    The list of accounts (addresses, servers, user names) stays only in this browser (back it up or move it under “Back up data”). Passwords are never stored, and codes you read are not either – both are gone once the page is closed. Nothing is sent to a server; the app also works offline.

    Careful: a code with a password is as secret as the password itself. Don’t let anyone photograph it and don’t share it.

    Libraries

    qrcode-generator (MIT) draws the QR codes; the browser itself (BarcodeDetector) or zxing-wasm (MIT) reads codes.

    KI-Agenten (WebMCP)

    Ein KI-Agent kann ein E-Mail-Konto (ohne Passwort) zur Liste hinzufügen, damit hier der QR-Code entsteht, und die Konten lesen – auch die eines gelesenen Codes, aber nie Passwörter. Scannen, Bilder öffnen und Passwörter eingeben bleiben bei dir. Das klappt in Browsern mit WebMCP; was ein Agent tut, siehst du sofort hier in der App. Daten löschen, Sicherungen laden, Einstellungen zurücksetzen, Kamera, Mikrofon, Standort und Dateien öffnen sind für Agenten nie möglich, und sie schicken nichts an Server.

    AI agents (WebMCP)

    An AI agent can add an email account (without password) to the list so the QR code is made here, and read the accounts – also those of a code you read, but never passwords. Scanning, opening pictures and typing passwords stay with you. This works in browsers with WebMCP; whatever an agent does shows up here in the app right away. Deleting data, loading backups, resetting settings, camera, microphone, location and opening files are never available to agents, and they send nothing to servers.
