    Anleitung & Hinweise

    Ein Editor für Textdateien aller Art: Programmcode (Python, JavaScript, C, C++, Java, Shell …), Daten und Einstellungen (JSON, XML, YAML, INI, CSV), Markdown, Protokolle und einfache Texte. Die Syntax wird farbig hervorgehoben.

    Bedienung

    • Öffnen (Ordner oben): eine oder mehrere Dateien vom Gerät wählen – oder auf die Fläche ziehen. Jede Datei, die Text enthält, lässt sich öffnen, egal welche Endung sie hat. Bilder, PDFs, Archive und Programme lehnt die App ab.
    • Ansehen zeigt die Datei nur an – auf dem Handy öffnet sich keine Tastatur, Markieren und Kopieren gehen trotzdem. Bearbeiten schaltet das Schreiben ein. Geöffnete Dateien starten im Ansehen, neue im Bearbeiten.
    • Die Sprache (für die Farben) erkennt die App an der Dateiendung, an Namen wie Makefile oder Dockerfile, an der ersten Zeile (#!/bin/bash) oder am Inhalt. Unten unter Sprache lässt sie sich selbst wählen; dort stehen auch Zeichenkodierung und Zeilenenden.
    • Suchen findet Text (ohne Unterschied zwischen Groß- und Kleinschreibung); beim Bearbeiten lässt er sich ersetzen – einzeln oder alle auf einmal. Enter springt zum nächsten Treffer, Strg+F öffnet die Suche.
    • Zeile springt zu einer Zeilennummer, Umbruch bricht lange Zeilen um (die Zeilennummer steht dann vor der ersten Bildschirmzeile), Kopieren kopiert die ganze Datei.
    • Beim Bearbeiten: Einrücken/Ausrücken (auch Tab/Umschalt+Tab; erst Esc, dann Tab verlässt das Textfeld), Enter behält die Einrückung der Zeile. Die App rückt so ein wie die Datei (Tabulator, 2 oder 4 Leerzeichen). Bei JSON macht Formatieren (unter Mehr) die Datei übersichtlich.
    • Herunterladen speichert die Datei mit ihrem Namen, ihrer Zeichenkodierung und ihren Zeilenenden. Teilen (oben, wenn das Gerät es kann) schickt sie an andere Apps.
    • Direkt in der Datei speichern (Chrome und Edge am Computer): Öffnest du eine Datei über Öffnen oder Öffnen mit, bleibt sie mit der App verknüpft. Der Knopf oben (Diskette) bzw. Strg+S schreibt die Änderungen in genau diese Datei zurück; ein Punkt am Knopf zeigt ungespeicherte Änderungen. Speichern unter … im Menü legt eine neue Datei an. Auf dem iPhone, in Firefox und Safari lädt der Knopf die Datei stattdessen herunter.
    • Im Menü ☰ liegen die Dateien (antippen zum Öffnen, daneben Teilen, Herunterladen, Löschen) und die Einstellungen (Zeilennummern, Umbruch, Schriftgröße, Tabulatorbreite).

    Hinweise

    • Gelesen werden UTF-8 (mit und ohne BOM), UTF-16 (mit BOM) und ältere Windows-Dateien (Windows-1252/Latin-1). Gespeichert wird in derselben Kodierung; Zeichen, die Windows-1252 nicht kennt, werden dabei zu „?“ – dann unter Sprache auf UTF-8 umstellen.
    • Dateien bis 2 MB. Bei sehr großen Dateien bleiben die Farben beim Bearbeiten aus, damit das Tippen flüssig bleibt; beim Ansehen sind sie da.
    • Alles wird automatisch in diesem Browser gespeichert und funktioniert offline; nichts wird hochgeladen. Der Platz im Browser ist begrenzt (einige MB für alle Dateien zusammen) – große Dateien herunterladen und hier löschen.
    • Bibliothek: highlight.js (BSD-3-Clause) für die Farben – rund 70 Sprachen.

    An editor for text files of any kind: program code (Python, JavaScript, C, C++, Java, shell …), data and settings (JSON, XML, YAML, INI, CSV), Markdown, logs and plain text. The syntax is highlighted in colour.

    How to use

    • Open (folder at the top): pick one or more files from the device – or drop them on the area. Any file that contains text can be opened, whatever its extension. Images, PDFs, archives and programs are refused.
    • View only shows the file – on a phone no keyboard pops up, selecting and copying still work. Edit turns on writing. Opened files start in view, new ones in edit.
    • The app recognises the language (for the colours) by the file extension, by names like Makefile or Dockerfile, by the first line (#!/bin/bash) or by the content. Under Language at the bottom you can choose it yourself; character encoding and line endings are there too.
    • Find searches the text (ignoring upper and lower case); while editing you can replace it – one by one or all at once. Enter jumps to the next match, Ctrl+F opens the search.
    • Line jumps to a line number, Wrap wraps long lines (the line number then stands in front of the first row), Copy copies the whole file.
    • While editing: Indent/Outdent (also Tab/Shift+Tab; first Esc, then Tab leaves the text field), Enter keeps the indentation of the line. The app indents like the file does (tab, 2 or 4 spaces). For JSON, Format (under More) lays the file out neatly.
    • Download saves the file with its name, character encoding and line endings. Share (at the top, if the device can) sends it to other apps.
    • Save straight into the file (Chrome and Edge on a computer): when you open a file with Open or Open with, it stays linked to the app. The button at the top (floppy disk) or Ctrl+S writes the changes back into exactly that file; a dot on the button shows unsaved changes. Save as … in the menu creates a new file. On iPhone, in Firefox and Safari the button downloads the file instead.
    • The menu ☰ holds the files (tap to open, next to it share, download, delete) and the settings (line numbers, wrapping, font size, tab width).

    Notes

    • Read are UTF-8 (with and without BOM), UTF-16 (with BOM) and older Windows files (Windows-1252/Latin-1). Saving uses the same encoding; characters Windows-1252 does not know become “?” – then switch to UTF-8 under Language.
    • Files up to 2 MB. For very large files the colours stay off while editing so typing stays smooth; when viewing they are there.
    • Everything is saved automatically in this browser and works offline; nothing is uploaded. Browser storage is limited (a few MB for all files together) – download large files and delete them here.
    • Library: highlight.js (BSD-3-Clause) for the colours – about 70 languages.

    Dateien an die App geben

    • Android: App installieren (☰ → Als App installieren). Dann die Datei in Galerie, Dateien-, Mail- oder Messenger-App teilen und „Code-Editor“ wählen – das klappt auch offline.
    • Windows/Computer: Als installierte App (Chrome oder Edge) steht sie unter Öffnen mit (Rechtsklick auf die Datei); als Standard-App öffnet sie Dateien per Doppelklick. Mit Edge erscheint sie auch im Teilen-Menü von Windows.
    • iPhone/iPad: Teilen an Web-Apps und Öffnen mit gibt es dort nicht – die Datei hier in der App auswählen.

    Giving files to the app

    • Android: install the app (☰ → Install as an app). Then share the file from the gallery, files, mail or messenger app and pick “Code Editor” – this works offline too.
    • Windows/computer: as an installed app (Chrome or Edge) it is listed under Open with (right-click the file); set as default app, it opens files with a double-click. With Edge it also appears in the Windows share menu.
    • iPhone/iPad: sharing to web apps and Open with do not exist there – choose the file here in the app.

    KI-Agenten (WebMCP)

    Ein KI-Agent kann die Liste der Dateien und deren Inhalt lesen und eine neue Datei anlegen. Bestehende Dateien ändern kann er nicht. Das klappt in Browsern mit WebMCP; was ein Agent tut, siehst du sofort hier in der App. Daten löschen, Sicherungen laden, Einstellungen zurücksetzen, Kamera, Mikrofon, Standort und Dateien öffnen sind für Agenten nie möglich, und sie schicken nichts an Server.

    AI agents (WebMCP)

    An AI agent can read the list of files and their content and create a new file. It cannot change existing files. This works in browsers with WebMCP; whatever an agent does shows up here in the app right away. Deleting data, loading backups, resetting settings, camera, microphone, location and opening files are never available to agents, and they send nothing to servers.
