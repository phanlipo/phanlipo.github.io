      Daten sichern & übertragen

      Einstellungen und Verläufe dieser App liegen nur in diesem Browser. Mit einer Sicherungsdatei lassen sie sich aufbewahren oder auf ein anderes Gerät bzw. in die installierte App übertragen.

      Anleitung & Hinweise

      Wandelt Sprachaufnahmen in Text um – mit dem Spracherkennungsmodell Whisper, das direkt im Browser läuft. Das Audio wird nicht hochgeladen.

      Sprachnachricht aus WhatsApp holen

      • Android, App installiert: Sprachnachricht lange antippen → Teilen → „Transkript“ wählen – die Datei landet direkt hier.
      • Android ohne Installation: Sprachnachricht teilen → z. B. „In Dateien speichern“; dann hier die .opus-Datei wählen.
      • iPhone: Sprachnachricht lange drücken → Weiterleiten → Teilen-Symbol → „In Dateien sichern“; dann hier wählen.
      • PC: WhatsApp Web/Desktop → Sprachnachricht herunterladen und hierher ziehen.

      Modelle

      • Beim ersten Transkribieren lädt der Browser das gewählte Modell einmalig von Hugging Face (dabei wird kein Audio übertragen). Danach liegt es im Browser und funktioniert auch offline.
      • base ist schnell und für deutsche Sprachnachrichten meist gut; small ist genauer, aber groß und auf dem Handy deutlich langsamer.
      • Mit Grafikkarten-Unterstützung (WebGPU) geht es deutlich schneller; dafür ist der einmalige Download von base größer (ca. 200 statt 75 MB). Die Auswahl zeigt die Größe für dieses Gerät. Bei „Rechnen mit: Automatisch“ nutzt small den Prozessor, damit der Download nicht auf über 500 MB wächst; mit „Grafikkarte“ lässt sich das erzwingen.
      • „Heruntergeladene Modelle“ zeigt den belegten Speicher und löscht die Modelle bei Bedarf.

      Tipps

      • Die Sprache fest einzustellen ist genauer und schneller als „Automatisch erkennen“.
      • Das Ergebnis lässt sich im Textfeld korrigieren und dann kopieren, speichern oder teilen.
      • Während der Umwandlung die Seite geöffnet lassen (das Display bleibt dafür an, wo der Browser das erlaubt).

      KI-Agenten (WebMCP)

      • Unterstützt der Browser WebMCP, kann ein KI-Assistent im Browser das aktuelle Transkript und den Verlauf lesen, z. B. um eine Sprachnachricht zusammenzufassen. Das Transkribieren startest weiterhin du. Ein Hinweis zeigt, wenn ein Agent etwas ausgelöst hat.
      • Löschen und Sicherungen sind für Agenten nicht zugänglich. Es werden keine Daten an Server gesendet.

      Spracherkennung macht Fehler – besonders bei Namen, Dialekt und Hintergrundgeräuschen. Wichtige Inhalte bitte gegenhören.

      Turns voice recordings into text – with the speech recognition model Whisper, running right in the browser. The audio is not uploaded.

      Getting a voice message out of WhatsApp

      • Android, app installed: long-press the voice message → Share → choose “Transcript” – the file arrives here directly.
      • Android without installing: share the voice message → e.g. “Save to Files”; then choose the .opus file here.
      • iPhone: long-press the voice message → Forward → share icon → “Save to Files”; then choose it here.
      • Computer: WhatsApp Web/Desktop → download the voice message and drag it here.

      Models

      • The first time you transcribe, the browser downloads the chosen model once from Hugging Face (no audio is sent). After that it is stored in the browser and also works offline.
      • base is fast and usually good for voice messages; small is more accurate, but large and much slower on a phone.
      • With graphics card support (WebGPU) it is much faster; the one-time download of base is bigger in exchange (about 200 instead of 75 MB). The list shows the size for this device. With “Compute with: Automatic”, small uses the processor so the download does not grow beyond 500 MB; “Graphics card” forces it.
      • “Downloaded models” shows the storage used and deletes the models if needed.

      Tips

      • Setting the language is more accurate and faster than “Detect automatically”. It starts with the language of the app.
      • The result can be corrected in the text field and then copied, saved or shared.
      • Keep the page open while converting (the screen stays on where the browser allows it).

      AI agents (WebMCP)

      • If the browser supports WebMCP, an AI assistant in the browser can read the current transcript and the history, e.g. to summarise a voice message. You still start the transcription yourself. A notice shows when an agent did something.
      • Deleting and backups are not available to agents. No data is sent to any server.

      Speech recognition makes mistakes – especially with names, dialect and background noise. Please listen again to important content.
