      Anleitung & Hinweise

      Öffnet eine KeePass-Datenbank (KeePass 2, KeePassXC, KeePassDX, Strongbox, KeePassium …) zum Nachschlagen: Einträge suchen, Passwort, Benutzername und Einmalcode kopieren. Ändern lässt sich hier nichts – die Datei bleibt, wie sie ist.

      Bedienung

      • KeePass-Datei (.kdbx) wählen, das Master-Passwort eingeben und, falls die Datenbank eine hat, die Schlüsseldatei wählen. Dann „Entsperren“.
      • Das Kopier-Symbol in der Liste kopiert direkt das Passwort. Ein Tipp auf den Eintrag zeigt alle Felder; jedes lässt sich einzeln kopieren, verborgene mit dem Auge anzeigen.
      • Einmalcodes (TOTP) aus KeePassXC und KeePass 2.47+ werden mit Restzeit angezeigt.
      • Das Schloss oben sperrt sofort. Ohne Bedienung sperrt die App nach der eingestellten Zeit von selbst (Einstellungen im Menü).
      • Der Papierkorb der Datenbank wird nicht angezeigt, Anhänge und ältere Versionen eines Eintrags auch nicht.

      Sicherheit – bitte lesen

      • Entschlüsselt wird nur auf diesem Gerät. Datei, Passwort und Inhalte gehen an keinen Server; die App läuft auch offline.
      • Für den Alltag sind eigene KeePass-Apps besser: KeePassDX (Android), KeePassium oder Strongbox (iPhone), KeePassXC (Computer). Sie können Passwörter direkt in Formulare eintragen und laufen nicht im Browser.
      • Diese App teilt sich die Adresse phanlipo.github.io mit vielen anderen Tools. Ein Fehler in einem davon könnte im Prinzip auch diese Seite erreichen. Deshalb hier nur lesen, die Datei nie hier speichern lassen, wenn du das Gerät mit anderen teilst, und nach dem Nachschlagen sperren.
      • Kopierte Passwörter liegen in der Zwischenablage, wo andere Apps sie lesen können. Die App leert sie nach 30 Sekunden – aber nur, wenn sie dann noch im Vordergrund ist; Browser erlauben es sonst nicht. Manche Tastaturen merken sich Kopiertes zusätzlich.
      • Beim Sperren wirft die App die entschlüsselten Daten weg. Ganz aus dem Arbeitsspeicher löschen kann ein Browser sie aber nicht sofort.

      Unterstützt

      • KDBX 3.1 und 4 mit AES-256 oder ChaCha20, Schlüsselableitung AES-KDF, Argon2d oder Argon2id; Passwort, Schlüsseldatei (XML, Binär, Hex) oder beides.
      • Nicht: KeePass 1 (.kdb), Twofish-Verschlüsselung, YubiKey/Challenge-Response.

      Gespeichert

      Nur die Einstellungen (sichern und übertragen unter „Daten sichern“). Ist „Datei merken“ an, liegt die verschlüsselte .kdbx im Speicher dieses Browsers, damit beim nächsten Mal nur das Passwort nötig ist. Passwort und Schlüsseldatei werden nie gespeichert. „Gemerkte Datei vergessen“ im Menü entfernt sie.

      Wenn es nicht klappt

      • Falsches Passwort? Groß-/Kleinschreibung und Tastaturbelegung prüfen. Wurde die Datenbank mit einer Schlüsseldatei angelegt, muss sie mitgewählt werden.
      • Sehr langsam oder Abbruch auf dem Handy: Argon2 mit viel Speicher (z. B. 1 GB) kann für den Browser zu viel sein. In KeePass(XC) unter Datenbank-Einstellungen → Verschlüsselung den Speicher verringern.
      • Die Datei muss die aktuelle Version sein: Bei Cloud-Ordnern vor dem Öffnen synchronisieren lassen.

      Opens a KeePass database (KeePass 2, KeePassXC, KeePassDX, Strongbox, KeePassium …) to look things up: search entries, copy password, user name and one-time code. Nothing can be changed here – the file stays as it is.

      How to use

      • Choose the KeePass file (.kdbx), enter the master password and, if the database uses one, choose the key file. Then “Unlock”.
      • The copy icon in the list copies the password right away. Tapping the entry shows all fields; each can be copied on its own, hidden ones shown with the eye.
      • One-time codes (TOTP) from KeePassXC and KeePass 2.47+ are shown with the time left.
      • The lock at the top locks at once. Without use, the app locks itself after the time set (settings in the menu).
      • The database’s recycle bin is not shown, nor are attachments and older versions of an entry.

      Security – please read

      • Decryption happens only on this device. File, password and contents go to no server; the app also works offline.
      • For everyday use, dedicated KeePass apps are better: KeePassDX (Android), KeePassium or Strongbox (iPhone), KeePassXC (computer). They can fill in passwords directly and do not run in the browser.
      • This app shares the address phanlipo.github.io with many other tools. A bug in one of them could in principle reach this page too. So only read here, do not let the file be kept here if you share the device, and lock after looking something up.
      • Copied passwords sit in the clipboard, where other apps can read them. The app clears it after 30 seconds – but only if it is still in the foreground then; browsers do not allow it otherwise. Some keyboards keep their own copy history.
      • On locking, the app drops the decrypted data. A browser cannot wipe it from memory right away, though.

      Supported

      • KDBX 3.1 and 4 with AES-256 or ChaCha20, key derivation AES-KDF, Argon2d or Argon2id; password, key file (XML, binary, hex) or both.
      • Not: KeePass 1 (.kdb), Twofish encryption, YubiKey/challenge-response.

      Stored

      Only the settings (back them up or move them under “Back up data”). With “Keep the file” on, the encrypted .kdbx stays in this browser’s storage, so next time only the password is needed. Password and key file are never stored. “Forget the kept file” in the menu removes it.

      If it does not work

      • Wrong password? Check upper/lower case and the keyboard layout. If the database was created with a key file, it has to be chosen too.
      • Very slow or aborted on the phone: Argon2 with a lot of memory (e.g. 1 GB) can be too much for the browser. Lower the memory in KeePass(XC) under database settings → encryption.
      • The file has to be the current version: let cloud folders sync before opening it.

      Dateien an die App geben

      • Android: App installieren (☰ → Als App installieren). Dann die Datei in Galerie, Dateien-, Mail- oder Messenger-App teilen und „KeePass“ wählen – das klappt auch offline.
      • Windows/Computer: Als installierte App (Chrome oder Edge) steht sie unter Öffnen mit (Rechtsklick auf die Datei); als Standard-App öffnet sie Dateien per Doppelklick. Mit Edge erscheint sie auch im Teilen-Menü von Windows.
      • iPhone/iPad: Teilen an Web-Apps und Öffnen mit gibt es dort nicht – die Datei hier in der App auswählen.

      Giving files to the app

      • Android: install the app (☰ → Install as an app). Then share the file from the gallery, files, mail or messenger app and pick “KeePass” – this works offline too.
      • Windows/computer: as an installed app (Chrome or Edge) it is listed under Open with (right-click the file); set as default app, it opens files with a double-click. With Edge it also appears in the Windows share menu.
      • iPhone/iPad: sharing to web apps and Open with do not exist there – choose the file here in the app.

      KI-Agenten (WebMCP)

      Ein KI-Agent kann im entsperrten Tresor nach Einträgen suchen (er bekommt nur Titel, Gruppe und Adresse), einen Eintrag anzeigen und den Tresor sperren. Passwörter, Benutzernamen, Notizen und Einmalcodes bekommt er nie, und entsperren kann er nicht. Das klappt in Browsern mit WebMCP; was ein Agent tut, siehst du sofort hier in der App. Daten löschen, Sicherungen laden, Einstellungen zurücksetzen, Kamera, Mikrofon, Standort und Dateien öffnen sind für Agenten nie möglich, und sie schicken nichts an Server.

      AI agents (WebMCP)

      An AI agent can search the unlocked vault for entries (it only gets title, group and address), show an entry and lock the vault. It never gets passwords, user names, notes or one-time codes, and it cannot unlock. This works in browsers with WebMCP; whatever an agent does shows up here in the app right away. Deleting data, loading backups, resetting settings, camera, microphone, location and opening files are never available to agents, and they send nothing to servers.
